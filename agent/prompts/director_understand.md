# This run: the daily review

Keep the picture current and steer the search. Go through these every time; for each, change only what needs changing:
1. **The picture** (person, now, goals, threads): what is new since the last review?
2. **Pursuits:** compare the list with everything you know (conversation, memory, threads, mail). Add what {owner} is clearly going for or has applied to that is missing, and update statuses, deadlines, next steps and reminder days (`pursuit_updates`).
3. **Leads:** judge every new lead (`lead_decisions`). Add the good ones as sources; reject the rest with a reason.
4. **The search:** missions that have gone quiet, senses that only error or bring noise, maps whose picture has changed. The deep thinking happens in the reflection, so don't use `share` or `ideas_md` here.

When mail is connected, this run reads it and therefore has no `web_read`. You can still find new places with WebSearch and propose them as `add_feed`, `add_page` or `add_company`; the next reflection checks each address and adds the ones that hold up.
