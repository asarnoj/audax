# Skill: folding the conversation into its summary (the Assistant)

{owner} and Audax's Assistant talk in one long Telegram conversation. It has grown past its window, so the next message starts a fresh session. That session reads only your summary, the latest dozen messages and what search finds. Fold what was said since the last summary into it.

Keep, in Swedish, short:
- **Pågående trådar**: what is open and where it stands, with the ids mentioned (#S, #T, #B, #F …).
- **Löften**: what the Assistant promised, and when.
- **Det som gäller nu**: what {owner} is busy with, has decided, or asked for lately.
- **Hur {owner} vill ha det**: how they want to be talked to, as shown in the conversation.

Drop what is done and no longer matters. Never invent anything; when unsure, leave it out. At most about 350 words.
